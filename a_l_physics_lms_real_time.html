A/L භෞතික විද්‍යාව - අසමසම මඟපෙන්වීම

පේරාදෙණිය විශ්වවිද්‍යාලයීය ඉංජිනේරු උපාධිධාරී, ජ්‍යෙෂ්ඨ භෞතික විද්‍යා දේශක ශානක සඳරුවන් විසින් මෙහෙයවනු ලබන උසස් පෙළ භෞතික විද්‍යා විශිෂ්ඨතා මධ්‍යස්ථානය. සියලුම A/L බැච් (2025 සිට 2060 දක්වා) සිසුන් සදහා සිද්ධාන්ත (Theory) හා පුනරීක්ෂණ (Revision) පන්ති.

නිවැරදිම මඟපෙන්වීම!

අපගේ පංතියේ විශේෂතා:

✓
සම්පූර්ණ සිද්ධාන්ත හා පුනරීක්ෂණ

සියලුම A/L බැච් සදහා විශේෂිත පාඩම් මාලා

✓
සරල ක්‍රමවේදය

ඕනෑම මට්ටමක සිසුවෙකුට තේරුම්ගත හැකි අයුරින්

✓
ප්‍රශ්න පත්‍ර සාකච්ඡාව

පසුගිය විභාග ගැඹුරින් විශ්ලේෂණය කිරීම

✓
ප්‍රායෝගික පරීක්ෂණ සිමියුලේෂන්

විෂය අවබෝධය පහසු කරන නවීන තාක්ෂණය

වීඩියෝ පාඩම් මාලාව (Video Vault)

ඔබගේ A/L කණ්ඩායම (Batch) සහ Stream Mode (Theory / Revision) අනුව පාඩම් නරඹන්න.

ටියුට්ස් සහ කෙටි සටහන් (Tutes & Notes)

ඔබගේ බැච් එකට අදාළ PDF ටියුට්ස් සහ අධ්‍යයන සටහන් මෙතැනින් බාගත කරගන්න.

ප්‍රායෝගික පරීක්ෂණ සිමියුලේෂන් (Simulations)

භෞතික විද්‍යා ප්‍රායෝගික පරීක්ෂණ සජීවීව අත්විඳින්න.

ගුරු පාලක මණ්ඩලය (Teacher Control Panel)

සාදරයෙන් පිළිගනිමු, ශානක සඳරුවන් සර්. (Live Cloud Sync Active)

ලියාපදිංචි වූ සිසුන් පාලනය සහ අනුමැතිය

සිසුවාගේ නම ඊමේල් ලිපිනය දුරකථන අංකය Batch Year Stream Mode තත්ත්වය (Approval) ක්‍රියාකාරකම්

නව වීඩියෝ පාඩමක් එක්කිරීම

පවතින වීඩියෝ පාඩම් ලැයිස්තුව (ඉවත් කිරීම සදහා)

ඕනෑම පාඩමක් පහසුවෙන් ඉවත් කිරීමට ඔබන්න.

නව Tute / Note එකතු කිරීම

පවතින Tute ලැයිස්තුව (ඉවත් කිරීම සදහා)

ඕනෑම Tute එකක් පහසුවෙන් ඉවත් කිරීමට ඔබන්න.

ප්‍රායෝගික සිමියුලේෂන් ලින්ක් එකතු කිරීම

පවතින Simulations ලැයිස්තුව (ඉවත් කිරීම සදහා)

ඕනෑම Simulation එකක් පහසුවෙන් ඉවත් කිරීමට ඔබන්න.
